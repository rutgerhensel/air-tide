# Air Tide - Kite Surfing Game

## 🎮 Play Now

**Live Game:** https://rutgerhensel.github.io/aigame/

## 📋 Game Overview

Air Tide is an exciting kite surfing adventure where you ride the waves and collect power-ups to achieve the highest scores!

## 🎯 How to Play

### Controls:
- **UP Arrow / SPACE:** Jump and fly
- **DOWN Arrow:** Dive underwater

### Game Mechanics:
1. **Start:** Press SPACE to begin
2. **Surf:** Stay on the wave surface to maintain speed
3. **Collect Wings:** Hit birds to steal their wings (x3 multiplier!)
4. **Avoid Obstacles:** Jump over rocks and buoys
5. **Score:** Collect points while airborne and in motion

### Power-ups:
- **x2 AIR:** When airborne (not on wave)
- **x3 WINGS:** When you have stolen bird wings

## 🌊 Features

- **Beautiful 2D graphics** with dynamic waves
- **Smooth physics** and kite surfing mechanics
- **Bird wing collection** for powerful boosts
- **High score tracking** with local storage
- **Responsive controls** for desktop and mobile

## 🚀 Technical Details

- Built with **p5.js** for graphics and physics
- Pure JavaScript with no external dependencies
- Optimized for smooth gameplay on all devices
- Includes particle effects for visual feedback

## 🎨 Visual Style

- **Ocean theme** with vibrant blues and warm colors
- **Kite flying** with dynamic wing animation
- **Wave simulation** using Perlin noise
- **Daytime adventure** with floating clouds

## 📊 Game Stats

- **Score multiplier:** Up to 3x
- **High score:** Saved locally in browser
- **Wave speed:** Increases with score
- **Bird spawning:** Random intervals

1. **Stay airborne** as long as possible for x2 multiplier
2. **Collect bird wings** for x3 multiplier (best strategy!)
3. **Time your jumps** to avoid obstacles
4. **Dive strategically** to avoid birds
5. **Practice wave timing** for smooth surfing
